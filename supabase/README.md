# Cloud Mode غير مفعّل
يتطلب موافقة المالك، تأكيد بيانات دخول جديدة، إعداد Auth وRLS وRealtime واختبارها على جهازين. لا تضع service_role key في ملفات المتصفح.


## التحديات المباشرة بين الحسابين
بعد نشر تحديث التحديات، شغّل مرة واحدة ملف `migrations/202611040003_add_direct_game_challenges.sql` في Supabase SQL Editor. ينشئ هذا الملف جدول الدعوات وسياسات القراءة ودوال الإرسال والقبول والرفض والإلغاء، ويضيف الجدول إلى Realtime. لا يحتاج إلى مفاتيح سرية جديدة.
