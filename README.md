# AYFAR WORLD ♡ — المرحلة الأولى

## التشغيل
فك الضغط وافتح `index.html` مباشرة. اختر أيوب أو فرحتي للدخول المحلي. لا يتطلب الأساس اتصالاً بالإنترنت؛ خط Tajawal اختياري من Google Fonts مع بدائل محلية.

## localhost وPWA
من مجلد المشروع نفّذ `python -m http.server 8000` ثم افتح `http://localhost:8000`. يعمل Service Worker على localhost أو HTTPS فقط، وليس عبر `file://`.

## ما يعمل الآن
- شاشة اختيار الشخصية والدخول المحلي.
- لوحة رئيسية عربية RTL متجاوبة.
- عرض أرصدة النقاط المحلية (تبدأ من صفر).
- تاريخنا الخاص وحساب الأيام ديناميكياً.
- تقييم اليوم مع ملاحظة وحفظ محلي.
- بطاقات تعريفية للألعاب العشر المعتمدة (المواصفات في GAMES-SPEC.md).
- حفظ الجلسة والتقييمات عبر localStorage.
- ملفات manifest وService Worker وأيقونة SVG.

## ما لم يكتمل بعد
الألعاب العشر بطاقات تعريفية فقط وليست ألعاباً مكتملة؛ راجع GAMES-SPEC.md لقواعد اللعب وآليات النقاط والمزامنة المقترحة. الالرسائل والظرف ولوحة الإدارة ونظام النقاط الفعلي وسجل النتائج والمزامنة السحابية لم تنفذ بعد. اختيار الشخصية ليس مصادقة آمنة. البيانات مرتبطة بالمتصفح والجهاز ولا تنتقل تلقائياً إلى هاتف آخر.

## Cloud Mode
لم يتم إعداد Supabase أو RLS أو Auth. يتطلب ذلك موافقة وإعداد مشروع سحابي، وتأكيد بيانات دخول جديدة. لا تضع `service_role key` في المتصفح.

## نسخ البيانات
التخزين المحلي تحت المفتاح `ol_sw_local_v1` في localStorage. التصدير والاستيراد بواجهة مخصصة سيضافان لاحقاً.

## الهوية البصرية
الاسم الرسمي للمشروع هو **AYFAR WORLD**. الهوية رومانسية وناعمة، وتعتمد الوردي الهادئ والبورغندي والأخضر مع خلفيات عاجية فاتحة.


## لعبة الشخصيات — النموذج الأولي 0.5.0
اللعبة السادسة أصبحت قابلة للتجربة محلياً: يختار كل لاعب شخصية سرية بالتناوب، ثم يطرح اللاعب سؤالاً نصياً وتكون إجابة الطرف الآخر نعم أو لا، وبعدها يحاول تخمين الشخصية. النقاط تحفظ في بيانات هذا المتصفح فقط. استخدموا تمرير الهاتف بين اللاعبين لحماية الاختيارات السرية.

**حدود النسخة الحالية:** لا يوجد تسجيل دخول حقيقي أو مزامنة بين Android وiPhone حتى الآن. يلزم إعداد Supabase Auth وRealtime وRLS ودوال آمنة لفرض الأدوار واحتساب النقاط قبل اللعب عن بعد.
