# AYFAR AI QUIZ — إعداد الربط الآمن

## ما الذي يفعله التكامل؟
- يولّد 15 سؤالاً عربياً جديداً عبر OpenAI Responses API في كل مباراة.
- التصنيفات: ثقافة عامة، علوم، تاريخ، جغرافيا، المغرب، رياضة، سينما، ألغاز.
- الصعوبة: متنوع (سهل/متوسط/صعب).
- لا يرسل الإجابة النموذجية إلى المتصفح قبل إرسال اللاعبين كليهما.
- يصحح الإجابات بالمعنى، ويكشف الإجابة والتفسير بعد اكتمال الإجابتين.
- يحتفظ بالأسئلة والإجابات النموذجية في جدول محمي لا يستطيع مستخدمو المتصفح قراءته.

## متطلبات التفعيل (مرة واحدة)

### 1) تطبيق ترحيل قاعدة البيانات
افتح Supabase Dashboard للمشروع، ثم SQL Editor، والصق محتوى:
`supabase/ai-quiz-migration.sql`
وشغّله مرة واحدة.

### 2) إضافة مفتاح OpenAI إلى أسرار Supabase
من Supabase Dashboard افتح Edge Functions → Secrets وأضف:
- Name: `OPENAI_API_KEY`
- Value: مفتاح API الخاص بحساب OpenAI.

لا تضع المفتاح في GitHub أو في ملفات `js/` أو في المتصفح. استخدام API يخضع لفوترة OpenAI منفصلة عن اشتراك ChatGPT.

### 3) نشر Edge Function
من نسخة المشروع المحلية، وبعد ربط Supabase CLI بالمشروع:
```bash
supabase link --project-ref zweughbuocvrytanqdzk
supabase functions deploy ayfar-ai-quiz
```

الدالة موجودة في:
`supabase/functions/ayfar-ai-quiz/index.ts`

تستخدم الدالة أسرار Supabase المدمجة للتحقق من جلسة المستخدم والوصول إلى الجدول الخاص، ولا تتطلب وضع service-role key في الموقع.

## الاختبار بعد التفعيل
1. افتح الموقع على الهاتفين وسجّل الدخول بالحسابين.
2. افتح AYFAR AI QUIZ وأنشئ المباراة وانضم من الهاتف الآخر.
3. يبدأ أيوب المباراة؛ يتم إنشاء 15 سؤالاً.
4. أرسل إجابة من هاتف أيوب. يجب أن تظهر حالة الانتظار فقط.
5. أرسل إجابة فرحتي. بعدها تظهر الإجابتان والتصحيح والحل والتفسير على الهاتفين.
6. انتقل للسؤال التالي حتى نهاية 15 سؤالاً.

## ملاحظات تشغيلية
- لا يمكن اختبار استدعاء OpenAI أو نشر Edge Function من GitHub Pages وحده.
- إذا لم تضف `OPENAI_API_KEY` أو لم تنشر الدالة، ستظهر رسالة إعداد/اتصال ولن تعمل المسابقة بعد.
- تم اعتماد `gpt-4o-mini` لتوليد الأسئلة والتصحيح المنظم؛ قد تظل هناك أخطاء معرفية نادرة، لذلك يعرض التطبيق تفسير الإجابة ولا ينبغي اعتبار النموذج مرجعاً أكاديمياً معصوماً.
- جدول الجلسات محمي بـ RLS ولا توجد سياسات قراءة للمتصفح؛ الوصول يتم عبر Edge Function بعد التحقق من هوية اللاعب وعضويته في المباراة.
